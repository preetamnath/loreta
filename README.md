# Loreta

Loreta is an umbrella repository for local-first productivity products.

## Products

- [Loreta Speak](speak/README.md): a local-only macOS menu bar dictation app.

## Repository Layout

- `speak/`: the Loreta Speak product line, with its own source, docs, scripts,
  and product-specific README.

Additional Loreta product lines can be added as sibling folders over time.
